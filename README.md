# Queen Care Android App

تطبيق أندرويد بسيط لمركز Queen Care للعناية بالبشرة والشعر.

## المميزات
- عرض خدمات البشرة والشعر
- عرض العروض
- زر حجز واتساب
- زر اتصال مباشر
- عنوان المركز
- ألوان وهوية Queen Care

## بيانات المركز
العنوان: الحوامدية - برج السلام الطبي - الدور الثالث أعلى معامل المدينة  
الهاتف: 01013005666  
واتساب: 01113777031

## طريقة الرفع على GitHub
1. افتح GitHub واعمل Repository باسم QueenCare-Android.
2. ارفع كل ملفات المشروع.
3. ادخل على Actions.
4. شغّل Build Android APK.
5. بعد انتهاء البناء، حمّل ملف QueenCare-APK من Artifacts.
